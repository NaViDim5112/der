# Сайт и форум World Role Play

Сайт, форум, база знаний, личный кабинет и админ-панель для SA-MP / open.mp сервера **World Role Play | Los Santos**.
Внешний вид сделан по образцу arizona-rp.com и forum.arizona-rp.com, но в своём стиле и со своим логотипом.

Один аккаунт работает везде: на форуме, в кабинете и в админке.

## Что есть

**Сайт** (`/`): главная с большим баннером (можно поставить своё видео из игры), статус сервера и онлайн, кнопки «Начать игру» и «Кабинет», новости из раздела форума, страницы «Начать игру» и «Сотрудничество».

**Форум** (`/forum/`):
- разделы и подразделы, «Подфорумы», «Приватный» для закрытых разделов, значок «НОВОЕ» и красная иконка у разделов с непрочитанным;
- темы с префиксами («На рассмотрении», «Одобрено», «Отказано», «Закрыто» и др.), закрепление, закрытие, перенос;
- жалобы и заявления по готовым формам: в разделах жалоб уже вставлены шаблоны, у новой темы автоматически ставится префикс «На рассмотрении»;
- сообщения с карточкой автора (аватар, должность, плашки групп «ЛИДЕР», «ПОЛЬЗОВАТЕЛЬ», регистрация, сообщения, реакции), реакции (лайк и другие), цитаты, спойлеры, подписи;
- редактор BB-кодов с панелью кнопок и предпросмотром;
- оповещения, личные сообщения, отслеживаемые темы, поиск, «Новые сообщения», «Прочитать всё»;
- профили с обложкой, стеной сообщений, подписками и игнором;
- «Быстрая навигация», «Пользователи онлайн», «Статистика форума», статус игрового сервера справа;
- светлая и тёмная тема, широкий режим, адаптация под телефон.

**База знаний** (`/wiki/`): категории и статьи, поиск.

**Личный кабинет** (`/cabinet/`): данные аккаунта, привязка игрового аккаунта и статистика из базы сервера (включается в настройках, см. ниже).

**Админ-панель** (`/admin/`): настройки сайта и сервера, разделы форума и их права, префиксы, группы, пользователи (бан, смена группы, пароль), меню слева, база знаний, журнал модерации.

## Установка на OpenServer

Нужно: OpenServer с PHP 7.4 или новее и MySQL / MariaDB.

### 1. Скопировать файлы

**OSPanel 6:** скопируйте папку `wrp-site` в `C:\OSPanel\home\` и переименуйте в `wrp.local`. В ней уже есть `.osp\project.ini`, где корень сайта указан как папка `public`. Откройте этот файл и проверьте, что `php_engine` и `web_engine` совпадают с модулями, которые у вас установлены (например `PHP-8.1` или `PHP-8.3`, `Apache-2.4`). Перезапустите OSPanel.

**OpenServer 5:** скопируйте папку `wrp-site` в `C:\OSPanel\domains\` и переименуйте в `wrp.local`. Затем в «Настройки - Домены» добавьте домен `wrp.local` с папкой `wrp.local\public` и перезапустите сервер.
Если папку `public` указать нельзя, сайт всё равно заработает через файл `.htaccess` в корне (Apache сам перенаправит запросы в `public`).

### 2. Включить модули

В настройках OpenServer включите PHP 7.4 или 8.x и MySQL или MariaDB (подойдёт уже работающая MariaDB 11.8 сервера: у сайта будет своя отдельная база).

### 3. Запустить установщик

Откройте в браузере `http://wrp.local/install/` и заполните форму:
- база данных: хост - адрес модуля MariaDB (в OpenServer 6 вида `127.0.1.19`, в OpenServer 5 - `127.0.0.1`), порт `3306`, пользователь и пароль MySQL, имя базы `wrp_site`. Установщик сам создаст базу. Игровую базу `worldrp` он не трогает;
- название сайта, IP и порт игрового сервера;
- логин, email и пароль главного администратора.

После установки **удалите папку `public/install`**.

### 4. Настроить под себя

Зайдите под администратором в `http://wrp.local/admin/`:
- «Настройки»: IP и порт сервера, ссылка на скачивание лаунчера (пока пусто - на сайте кнопка «Скоро»), ссылки на Discord, VK, Telegram, YouTube, ссылка на видео для кнопки «Видео об игре»;
- «Разделы форума»: разделы уже настроены под мод (Правительство, Департамент полиции, жалобы с анкетами); новые организации добавляйте здесь, когда они появятся в игре. Там же конструктор анкет для жалоб и заявлений;
- «Группы» и «Пользователи»: выдайте права администрации, лидерам - группу «Лидер».

Своё видео или картинку для главной положите в `public/assets/media/` (файл `hero.mp4` или `hero.jpg`), подробности в `public/assets/media/README.txt`.

## Подключение игровой базы (кабинет)

По умолчанию выключено. Сайт будет только ЧИТАТЬ базу мода `worldrp`, поэтому заведите для него отдельного пользователя MySQL с правом только SELECT на таблицу `accounts`.

В файле `config/config.php` найдите блок `game_db` и укажите:
- `enabled` => `true`;
- данные подключения к базе мода (хост, порт, имя базы, пользователь, пароль);
- `table` - таблица аккаунтов, `col_name` - колонка с ником, `col_pass` - колонка с паролем, `col_salt` - колонка с солью (если есть). Имена колонок сверьте с модом;
- `hash` - как мод хранит пароль: `auto` (bcrypt и старые SHA256 с солью, как в моде World RP), `bcrypt`, `sha256`, `sha256_salt` (SHA256_PassHash), `whirlpool` (WP_Hash), `md5`, `sha1` или `plain`;
- `charset` - `cp1251` или `latin1`, если в базе русский текст в cp1251;
- `stats` - какие колонки показать в кабинете и как их подписать.

После этого игроки смогут привязать игровой аккаунт в кабинете и восстановить пароль от форума через игровой пароль.

## Чтобы сайт видели игроки

OpenServer рассчитан на работу на своём компьютере. Чтобы сайт открывался у других людей, нужно пробросить порт 80 на роутере, разрешить его в брандмауэре Windows и привязать домен или внешний IP. Надёжнее со временем перенести сайт на хостинг или VPS: файлы и база переносятся как есть.

## Безопасность

- Пароли хранятся в виде хэша (bcrypt), формы защищены от CSRF, весь текст пользователей экранируется, BB-коды проходят через белый список.
- Аватары и обложки пересохраняются через GD, в папке `uploads` запрещён запуск PHP.
- Есть ограничение попыток входа, регистрации и частоты сообщений.
- В `config/config.php` держите `'debug' => false` на рабочем сайте.
- На рабочий сервер не копируйте папку `tests/`, после установки удалите `public/install`.
- Домен должен смотреть в папку `public/`. Тогда `app/`, `config/`, `sql/`, `storage/` и `tests/` из браузера недоступны.

### Если вместо Apache используется Nginx

Nginx не читает файлы `.htaccess`, поэтому те же запреты нужно прописать в конфиге сайта:

```nginx
root /путь/к/wrp-site/public;
index index.php;

# скрытые файлы (.htaccess, .git), кроме .well-known
location ~ /\.(?!well-known) { deny all; }

# в папке загрузок никакие скрипты не выполняются
location ^~ /uploads/ {
    location ~* \.(php\d?|phtml|phar|pht|phps|cgi|pl|py)(\.|$) { deny all; }
    add_header X-Content-Type-Options nosniff;
}

location ~ \.php$ {
    try_files $uri =404;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_pass 127.0.0.1:9000;
}
```

## Для разработчика

- PHP без фреймворков, совместимость с PHP 7.4. Точка входа каждой страницы - `app/bootstrap.php`, все файлы `app/lib/*.php` подключаются автоматически.
- Запросы к базе только через `db_one / db_all / db_val / db_exec / db_insert / db_update` с параметрами.
- Вывод текста через `e()`, BB-коды через `bbcode()`, ссылки через `url()`.
- Схема базы: `sql/schema.sql`, стартовые данные: `sql/seed.sql`.
- Тесты: `php tests/bbcode_test.php` (BB-коды и XSS), `tests/shot.js` (скриншоты страниц через Playwright), `tests/dev_seed.php` (демо-данные).
