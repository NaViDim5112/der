# Форум в игре: ноутбук, компьютер, планшет

Форум World RP можно открыть с игровых устройств (ноутбук, компьютер, планшет в доме) во встроенном браузере клиента (CEF).
Сайт для этого готов: компактный вид, вход без пароля по ссылке от сервера игры, кнопка «Закрыть», новости в JSON.
Со стороны мода и клиента нужно: предмет-устройство, окно CEF и формирование ссылки (пример на Pawn ниже).

## Что есть на сайте

| Что | Адрес | Зачем |
|---|---|---|
| Режим устройства | любая страница с `?device=laptop`, `pc`, `tablet` или `phone` | Запоминается до закрытия браузера (cookie `wrp_device`). Нет подвала и фоновых эффектов, правая колонка уходит вниз, кнопки крупнее на планшете, внизу справа кнопка «Закрыть». `?device=off` - обычный сайт. |
| Вход из игры | `/forum/game-login.php?...` | Ссылку подписывает сервер игры, игрок входит на форум без пароля. Ссылка одноразовая, живёт 2 минуты. |
| Новости | `/api/news.php?limit=10` | JSON для приложения «Новости» на планшете или для лаунчера, формат в `docs/API.md`. |
| Закрытие | кнопка «Закрыть» и клавиша Esc | Сообщает игре, что окно можно закрыть (ниже, «Закрытие окна»). |

Размеры окна, под которые проверен вид: ноутбук 1280x720, планшет 1024x768, телефон 390x844. Подойдёт любой размер от 360 px по ширине.

## Как открыть форум с устройства

Лучше открывать форум как обычную страницу во встроенном браузере (CEF, сам браузер внутри рамки ноутбука или планшета), а не в `iframe` внутри своего интерфейса. Тогда ничего на сайте настраивать не нужно, вход сохраняется.

1. Игрок использует устройство (ноутбук, компьютер или планшет в доме).
2. Сервер игры формирует подписанную ссылку (ниже) и открывает её в CEF у этого игрока.
3. Сайт проверяет подпись, находит аккаунт форума, к которому привязан игровой ник, и пускает игрока на `/forum/` (или на `return`).
4. Если ник ещё не привязан к форуму, сайт предложит войти или зарегистрироваться и привяжет ник сам. Отдельная игровая база для этого не нужна: ник подтверждает подпись сервера.

Без входа из игры можно просто открыть `https://АДРЕС_САЙТА/forum/?device=laptop`. Тогда игрок входит на форум своим логином и паролем.

Если у игрока на форуме включена двухфакторная защита, после ссылки сайт попросит код из приложения, как при обычном входе.

## Ссылка входа

```
https://АДРЕС_САЙТА/forum/game-login.php?nick=Имя_Фамилия&ts=ВРЕМЯ&nonce=СЛУЧАЙНО&device=laptop&sig=ПОДПИСЬ[&return=/forum/forum.php?id=52]
```

- `nick` - ник игрока в формате `Имя_Фамилия` (латиница, по 2-20 букв, одно подчёркивание);
- `ts` - время в секундах Unix (`gettime()`). Часы сервера игры и сайта должны совпадать с точностью до 2 минут;
- `nonce` - 8-64 латинских букв и цифр, у каждой ссылки свои (повторно ссылка не сработает);
- `device` - `laptop`, `pc`, `tablet`, `phone` или пусто;
- `return` - необязательно: внутренний адрес форума, куда перейти после входа. Должен начинаться с `/`, в URL закодировать (`%2F`, `%3F`, `%3D`, `%26`);
- `sig` - подпись: SHA256 от строки `wrp-sso|nick|ts|nonce|device` с приклеенным в конце ключом, в HEX. Это ровно то, что считает `SHA256_PassHash(строка, ключ, результат)` в SA-MP / open.mp. Регистр букв не важен.

Пример (проверьте свою реализацию на нём):

```
строка:  wrp-sso|Ivan_Petrov|1700000000|abc123xyz789|laptop
ключ:    example-secret-0123456789abcdefXYZ
подпись: SHA256("wrp-sso|Ivan_Petrov|1700000000|abc123xyz789|laptopexample-secret-0123456789abcdefXYZ")
```

Проверка порядка (пример из вики SA-MP): `SHA256_PassHash("test", "78sdjs86d2h")` = `CD16A1C8BF5792B48142FF6B67C9CB5B1BDC7260D8D11AFBA6BCDE0933A3C0AF`.

### Пример на Pawn (open.mp)

Набросок для мода: ключ держать вне git (как `mysql.ini`), адрес сайта - в настройках сервера.

```pawn
#define FORUM_URL "https://world-rp.ru"      // адрес сайта (как 'site_url' в config.php сайта)
// FORUM_SSO_SECRET - тот же ключ, что 'game_sso' => 'secret' в config.php сайта, НЕ в репозитории

stock Forum_BuildUrl(playerid, const device[], url[], size = sizeof url)
{
    static const chars[] = "abcdefghijklmnopqrstuvwxyz0123456789";
    new nick[MAX_PLAYER_NAME], nonce[17], data[160], sig[65], ts = gettime();
    GetPlayerName(playerid, nick, sizeof nick);
    for (new i = 0; i < 16; i++) {
        nonce[i] = chars[random(sizeof chars - 1)];
    }
    nonce[16] = EOS;
    format(data, sizeof data, "wrp-sso|%s|%d|%s|%s", nick, ts, nonce, device);
    SHA256_PassHash(data, FORUM_SSO_SECRET, sig, sizeof sig);
    format(url, size, "%s/forum/game-login.php?nick=%s&ts=%d&nonce=%s&device=%s&sig=%s",
        FORUM_URL, nick, ts, nonce, device, sig);
}
```

Дальше URL открывается в CEF у игрока средствами клиента (своё ядро клиента с CEF или CEF-плагин).
Если в вашей версии open.mp нет `SHA256_PassHash`, подойдёт любая SHA256 той же строки с ключом в конце.

## Настройка сайта (`config/config.php`)

```php
'site_url' => 'https://world-rp.ru',      // адрес сайта без пути
'game_sso' => [
    'enabled' => true,
    'secret'  => 'длинная-случайная-строка-от-32-символов',   // тот же ключ в моде
    'max_age' => 120,                      // сколько секунд живёт ссылка
],
```

Только если форум открывается в `iframe` внутри своего интерфейса с другого адреса:

```php
'frame_ancestors' => ['http://127.0.0.1:8095'],   // адреса интерфейса, которым можно встраивать сайт
'cookie_samesite' => 'None',                       // иначе вход в iframe не сохранится; работает только по HTTPS
```

После обновления сайта нажмите «Обновить базу» в админ-панели (нужно обновление `0004_game_sso.sql`).

## Закрытие окна

Кнопка «Закрыть» (и Esc, если курсор не в поле ввода) делает три вещи сразу, игра выбирает подходящую:

- `cef.emit('wrp:forum_close')` - если в странице есть объект `cef` с методом `emit` (CEF-плагины SA-MP, своё ядро клиента);
- событие окна `wrp:forum_close` (`window.addEventListener('wrp:forum_close', ...)`) - для своего интерфейса;
- `window.parent.postMessage({type: 'wrp:forum_close'}, '*')` - если форум открыт в `iframe`.

По этому событию клиент закрывает окно CEF и возвращает управление игроку.

## Безопасность

- Ключ подписи знает только сервер игры и сайт. В клиент и в публичный репозиторий его не передавать.
- Ссылка одноразовая (сайт запоминает `nonce`) и живёт `max_age` секунд. Повтор, чужая подпись, старое время и чужой `return` отклоняются.
- На рабочем сайте нужен HTTPS: ссылку и cookie входа не должны видеть посторонние.
- Двухфакторная защита форума действует и при входе из игры.
- Проверка: `BASE=http://127.0.0.1:8080 php tests/ingame_test.php` (нужен включённый `game_sso` в config.php).

## Что сделать со стороны мода и клиента

- Предмет или мебель «Ноутбук», «Компьютер», «Планшет» в доме и действие «Открыть форум».
- Окно CEF нужного размера в рамке устройства, курсор и блокировка управления, пока окно открыто.
- Формирование ссылки (пример выше) и открытие её в CEF, обработка `wrp:forum_close`.
- По желанию - приложение «Новости» на планшете из `/api/news.php` и кнопки быстрого перехода (например, «Подать жалобу»: `return=/forum/new-thread.php?node=52`).
