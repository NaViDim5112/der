Привет! Форум и сайт World RP готовы и проверены. Задача для тебя: встроить форум в игровые устройства в домах (ноутбук, компьютер, планшет), чтобы игрок открывал форум прямо в игре. Сторона сайта уже готова, нужна сторона мода и клиента.

- GitHub `NaViDim5112/der` (публичный), ветка `claude/samp-project-audit-pofk1k`, папка `wrp-site`.
- Архив: https://github.com/NaViDim5112/der/archive/refs/heads/claude/samp-project-audit-pofk1k.zip
- Главное для тебя: `wrp-site/docs/INGAME.md` (полная инструкция), `wrp-site/docs/API.md` (новости в JSON), `wrp-site/README.md` (установка на OpenServer).
- Сайт: свой PHP 7.4+, MariaDB, база `wrp_site` (игровую `worldrp` не трогает). На ПК Дмитрия ещё не установлен: OpenServer 6, `C:\OSPanel\home\wrp.local`, MariaDB 127.0.1.19.

**Что уже есть на сайте для игры**
1. **Компактный вид для устройства.** Любая страница с `?device=laptop|pc|tablet|phone`: без подвала и фона, крупнее кнопки на планшете, кнопка «Закрыть». Проверено на 1280x720, 1024x768 и 390x844.
2. **Вход без пароля** по одноразовой ссылке (живёт 120 с), которую подписывает сервер игры:
   `/forum/game-login.php?nick=Имя_Фамилия&ts=UNIX&nonce=8-64[A-Za-z0-9]&device=laptop&sig=HEX[&return=/forum/...]`
   - `sig` = `SHA256_PassHash("wrp-sso|nick|ts|nonce|device", КЛЮЧ)`, то есть SHA256 от строки с ключом в конце, HEX (регистр не важен).
   - Проверка: `SHA256_PassHash("test","78sdjs86d2h")` = `CD16A1C8BF5792B48142FF6B67C9CB5B1BDC7260D8D11AFBA6BCDE0933A3C0AF`.
   - Если ник не привязан к форуму, сайт предложит войти или зарегистрироваться и привяжет ник сам. 2FA форума при этом соблюдается.
   - Пример Pawn-функции `Forum_BuildUrl` - в `docs/INGAME.md`.
3. **Закрытие окна.** Кнопка «Закрыть» и Esc вызывают `cef.emit('wrp:forum_close')`, событие окна `wrp:forum_close` и `postMessage({type:'wrp:forum_close'})` родителю (если форум в iframe).
4. **Новости для приложения на планшете:** `GET /api/news.php?limit=10` (JSON, CORS `*`).

**Что нужно сделать в моде и клиенте**
- Предмет или мебель «Ноутбук», «Компьютер», «Планшет» в доме и действие «Открыть форум» (по желанию быстрые кнопки, например «Подать жалобу»: `return=/forum/new-thread.php?node=52`).
- Окно CEF в рамке устройства, курсор и блокировка управления, пока окно открыто. Форум открывать как страницу в CEF, не в iframe (тогда на сайте ничего настраивать не надо).
- Сформировать подписанную ссылку на сервере и открыть её в CEF. Обработать `wrp:forum_close`: закрыть окно и вернуть управление.
- Ключ подписи: длинная случайная строка от 32 символов. Хранить вне git (как `mysql.ini`) и в клиент не отдавать. Тот же ключ кладётся в `config/config.php` сайта:
  ```php
  'site_url' => 'https://адрес-сайта',
  'game_sso' => ['enabled' => true, 'secret' => '...', 'max_age' => 120],
  ```
  Часы сервера игры и сайта должны совпадать с точностью до 2 минут.
- Если всё же нужен iframe внутри своего интерфейса: `'frame_ancestors' => ['http://адрес-интерфейса']` и `'cookie_samesite' => 'None'`. Это работает только по HTTPS.
