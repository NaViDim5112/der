## Правила общения и работы
- Отвечать по-русски, коротко и прямо. Без длинного тире (только дефис «-»), без «ИИ-нумерации».
- Основной сервер, мод, конфиг и БД не менять без разрешения. Эксперименты - на тестовой копии.
- Исходники мода в cp1251: читать через iconv, сохранять обратно в cp1251.
- Репозиторий публичный: никаких паролей, IP с паролями, дампов БД. `wrp-site/config/config.php` в .gitignore.

## Сайт и форум (wrp-site)
- Свой движок на PHP без фреймворков под OpenServer (Apache/Nginx, PHP 7.4-8.x, MySQL/MariaDB). Один аккаунт на сайт, форум, кабинет и админку.
- Внешний вид повторяет forum.arizona-rp.com (тёмная тема XenForo) и arizona-rp.com, но в своём бренде: логотип - градиентная «W» с солнцем, акцент - градиент оранжевый-красный-розовый.
- Структура: `app/bootstrap.php`, `app/lib/*.php` (подключаются все автоматически), `public/` (корень сайта: `index.php` лендинг, `forum/`, `wiki/`, `cabinet/`, `admin/`, `install/`), `sql/schema.sql` + `sql/seed.sql`, `config/config.example.php`, `storage/`.
- Код: совместимость с PHP 7.4 (без match, ?->, именованных аргументов). Запросы только через `db_*` с параметрами; один именованный плейсхолдер нельзя повторять в запросе. Вывод через `e()`, BB-коды через `bbcode()`, ссылки через `url()`, формы с `csrf_field()` и `csrf_check()`.
- Игровая база (кабинет, привязка игрового аккаунта) настраивается в `config.php -> game_db` (таблица, колонки, тип хэша: bcrypt / sha256 / sha256_salt / whirlpool / md5 / sha1 / plain, cp1251). По умолчанию выключено - нужна структура таблицы аккаунтов из мода `E:\SAMP`.
- Разделы форума (фракции, жалобы и т.д.) заведены общие, их надо сверить с реальными фракциями мода и поправить в админке.

## Тестирование в облаке
- `apt-get install mariadb-server`, запуск `mysqld_safe --user=mysql &`, база `wrp` (user wrp/wrp): `mysql wrp < sql/schema.sql && mysql wrp < sql/seed.sql && php tests/dev_seed.php`.
- `config/config.php` для теста: installed=true, db wrp/wrp, debug=true.
- Сервер: `php -S 127.0.0.1:8080 -t public`. Скриншоты: `NODE_PATH=/opt/node22/lib/node_modules node tests/shot.js out.png /forum/ --login admin:admin12345`.
- BB-коды: `php tests/bbcode_test.php` (XSS и вывод).
